PROJEKT 25
PRESTIGE AI DIAGNOSTIC ASSISTANT
==================================================

Repo:

prestige-ai-diagnostic-assistant

Cel:

analiza raportów wygenerowanych przez inne narzędzia Prestige Tech.

Program NIE powinien wykonywać samodzielnie działań administracyjnych.

Input:

JSON

pochodzący np. z:

Windows Toolkit
Security Check
Internet Diagnostic
Malware Triage
System Snapshot
Network Snapshot
ADB Diagnostic

Stwórz warstwę:

normalization
rules
scoring
AI provider abstraction

Najpierw program ma mieć działający lokalny rule engine bez AI.

Przykład:

{
    "disk_free_percent": 4,
    "packet_loss": 8,
    "defender_enabled": true,
    "critical_errors": 3
}

Rule engine:

mało miejsca
packet loss
błędy systemowe

Dopiero jako opcjonalny moduł umożliw integrację z zewnętrznym modelem AI.

Klucze API:

NIGDY w kodzie.

Użyj:

.env
environment variables

Program musi jasno zaznaczać, czy dane opuszczają komputer.

Domyślnie:

LOCAL MODE.

KROK 8
Dodaj raportowanie.

KROK 9
Dodaj README.

KROK 10
Dodaj wersję v0.1.0.

KROK 11
Przejdź do następnego projektu.

brakuje informacji koniecznej do podjęcia decyzji
operacja może być destrukcyjna
potrzebny jest klucz API
potrzebny jest konkretny zewnętrzny link
istnieją dwie istotnie różne architektury i wybór wpłynie na cały projekt
